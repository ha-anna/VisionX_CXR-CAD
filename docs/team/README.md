## Weekly Contribution Log

**Period:** September 1–December 20, 2026  
**Maintained by:** Anna, team leader

The weekly contribution log records each teammate’s work, outcomes, and collaboration throughout the project. It provides supporting evidence for the final individual contribution summary.

### Recording Guidelines

- Update entries weekly using issues, pull requests, reviews, experiment logs, meeting notes, and deliverables.
- Describe each person’s specific contribution and its impact. Clearly distinguish completed, ongoing, and blocked work.
- Include implementation, data preparation, experiments, testing, documentation, reviews, coordination, and presentation work.
- For shared tasks, explain each teammate’s role.
- Link supporting evidence where available. Use dated notes for activities without a GitHub artifact, such as planning or paired debugging.
- Mark uncertain historical information as **Not yet verified**. Record **No project activity reported** only when confirmed.
- Ask teammates to verify their entries and record any corrections.
- Assess contributions in context, considering task difficulty and outcomes rather than commit counts, lines of code, or task totals.
