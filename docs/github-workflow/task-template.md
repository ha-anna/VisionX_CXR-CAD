# Task Template

Copy the title and description below into a new GitHub Issue. Replace the placeholders and remove anything you do not need.

**Title:** `[CATEGORY] Action + specific outcome`

Example: `[INFRA] Verify GitHub workflow`

## Branch

`<issue-number>-<short-task-description>`

Use lowercase words separated by hyphens. Leave out `#` and the title's category prefix. After creating the Issue, replace the placeholder with its actual number and save the branch name in this description.

Example for Issue #6: `6-verify-github-workflow`

Create this branch from the Issue's **Development** section, using `main` as the base.
